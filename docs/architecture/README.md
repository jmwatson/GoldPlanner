# GoldPlanner UML Documentation

PlantUML source for the current architecture after GOL-31 and the GOL-32 audit.

- `01_component_packages.puml` — package/module boundaries and dependencies
- `02_event_flow.puml` — Blizzard events, domain events, and UI subscriptions
- `03_gold_history_sequence.puml` — representative money → history → UI flow
- `04_ui_event_dependencies.puml` — UI event dependency matrix
- `05_world_quests_sequence.puml` — UI-local Blizzard event ownership

The `.puml` files are editable source documents and can be rendered with PlantUML.
